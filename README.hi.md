## विशेषताएं

### Dockerfile कॉन्फ़िगरेशन

- **बेस इमेज**: Docker बेस इमेज का नाम और संस्करण कॉन्फ़िगर करें (डिफ़ॉल्ट: `node:24`)
- **सॉफ्टवेयर चयन**: इंस्टॉल करने के लिए अतिरिक्त सॉफ्टवेयर चुनें:
  - ffmpeg (ऑडियो/वीडियो प्रोसेसिंग)
  - Flutter (Dart और Android SDK शामिल)
  - Go
  - ImageMagick (इमेज प्रोसेसिंग)
  - Python 3
  - Rust (Cargo पैकेज मैनेजर सहित)
  - TypeScript
  - uv (तेज़ Python पैकेज इंस्टॉलर, Python की सिफारिश करता है)
  - Ollama (ओपन-सोर्स मॉडल का उपयोग करने के लिए स्थानीय Ollama इंस्टेंस से कनेक्ट करें)
- **संस्करण कॉन्फ़िगरेशन**: सॉफ्टवेयर संस्करण Docker बिल्ड आर्ग्युमेंट्स के माध्यम से कॉन्फ़िगर किए जाते हैं (उदा: `--build-arg GO_VERSION=1.22.0`)
- **कस्टम APT पैकेज**: कंटेनर में इंस्टॉल करने के लिए अतिरिक्त Debian/Ubuntu पैकेज जोड़ें
- **कस्टम NPM पैकेज**: ग्लोबली इंस्टॉल करने के लिए अतिरिक्त NPM पैकेज जोड़ें, `root` या `node` उपयोगकर्ता के रूप में इंस्टॉल करने का विकल्प
- **कस्टम RUN कमांड**: Docker इमेज बिल्ड के दौरान चलाने के लिए कस्टम shell कमांड जोड़ें, `root` या `node` उपयोगकर्ता के रूप में चलाने का विकल्प

### docker-compose.yaml कॉन्फ़िगरेशन

- **एनवायरनमेंट वेरिएबल्स**: अपनी `.env` फ़ाइल के लिए एनवायरनमेंट वेरिएबल्स कॉन्फ़िगर करें
- **संरक्षित फ़ाइलें**: खाली रीड-ओनली फ़ाइलें माउंट करके सुरक्षित की जाने वाली फ़ाइलें निर्दिष्ट करें (`.env.local` जैसी संवेदनशील फ़ाइलों तक पहुंच रोकता है)

### settings.json कॉन्फ़िगरेशन

- **अनुमति नियम**: फ़ाइल एक्सेस प्रबंधित करने के लिए Claude Code अनुमतियाँ कॉन्फ़िगर करें
  - `Allow` - स्वचालित रूप से अनुमत ऑपरेशनों के लिए नियम
  - `Ask` - उपयोगकर्ता पुष्टि की आवश्यकता वाले नियम
  - `Deny` - हमेशा अस्वीकृत होने वाले नियम
- **समर्थित निर्देश**:
  - `Read()` - निर्धारित करता है कि Claude कौन सी फ़ाइलें पढ़ सकता है (उदा: `Read(src/**)`)
  - `Edit()` - निर्धारित करता है कि Claude कौन सी फ़ाइलें संपादित कर सकता है (उदा: `Edit(.env)`)
  - `WebFetch()` - नेटवर्क एक्सेस नियंत्रित करता है (उदा: `WebFetch(https://api.github.com:*)`)
- **स्वचालित एकीकरण**: संरक्षित फ़ाइलें स्वचालित रूप से `Read()` अस्वीकृति नियमों के रूप में जोड़ी जाती हैं
- **Glob पैटर्न समर्थन**: रिकर्सिव मैचिंग के लिए `src/**` जैसे पैटर्न का उपयोग करें

### DevContainer कॉन्फ़िगरेशन (VS Code / GitHub Codespaces)

- **VS Code एकीकरण**: VS Code Dev Container के लिए `devcontainer.json` जेनरेट करें
- **GitHub Codespaces**: GitHub Codespaces डेवलपमेंट के लिए संगत कॉन्फ़िगरेशन
- **एक्सटेंशन**: स्वचालित रूप से इंस्टॉल करने के लिए VS Code एक्सटेंशन कॉन्फ़िगर करें
- **सेटिंग्स**: कंटेनर वातावरण के लिए VS Code सेटिंग्स परिभाषित करें
- **Features**: Dev Container Features जोड़ें (जैसे: GitHub CLI, अतिरिक्त भाषाएं)
- **पोर्ट फ़ॉरवर्डिंग**: कंटेनर से फ़ॉरवर्ड करने के लिए पोर्ट कॉन्फ़िगर करें
- **लाइफ़साइकल कमांड**: post-create, post-start और post-attach इवेंट के लिए कमांड सेट करें
- **अनुशंसित एक्सटेंशन**: चयनित सॉफ़्टवेयर के आधार पर स्वचालित एक्सटेंशन अनुशंसाएं

### कीबोर्ड शॉर्टकट

सभी शॉर्टकट Windows/Linux पर `Ctrl` और macOS पर `⌘` (Cmd) का उपयोग करते हैं।

| शॉर्टकट | क्रिया |
| -------- | ------ |
| `Ctrl/⌘ + S` | ZIP डाउनलोड करें |
| `Ctrl/⌘ + B` | साइडबार टॉगल करें |
| `Ctrl/⌘ + E` | प्रीव्यू पेन टॉगल करें |
| `Ctrl/⌘ + Z` | अनडू |
| `Ctrl/⌘ + Y` | रीडू |
| `Ctrl/⌘ + Shift + Z` | रीडू (वैकल्पिक) |
| `Ctrl/⌘ + Shift + D` | डार्क/लाइट मोड टॉगल करें |
| `Ctrl/⌘ + Shift + X` | डिफ़ॉल्ट पर रीसेट करें |
| `Ctrl/⌘ + Shift + L` | भाषा स्विचर खोलें |
| `Ctrl/⌘ + 1-5` | सेक्शन पर स्विच करें (1=Dockerfile, 2=Docker Compose, 3=CLAUDE.md, 4=settings.json, 5=DevContainer) |
| `Ctrl/⌘ + /` | कीबोर्ड शॉर्टकट सहायता खोलें |
| `Escape` | डायलॉग बंद करें |

हेडर में सेटिंग्स मेनू से कीबोर्ड शॉर्टकट सहायता डायलॉग खोलें।

### ऑटोसेव मेकेनिज्म

ऑटोसेव फ़ीचर को हेडर में सेव आइकन का उपयोग करके टॉगल किया जा सकता है:

| आइकन           | स्थिति    | व्यवहार                                                          |
| -------------- | --------- | ---------------------------------------------------------------- |
| 💾 (सेव)       | सक्षम     | सभी परिवर्तन स्वचालित रूप से localStorage में सेव होते हैं        |
| 🚫💾 (बंद)     | अक्षम     | परिवर्तन सेव नहीं होते; मौजूदा सेव किया गया डेटा क्लियर हो जाता है |

**यह कैसे काम करता है:**

- **ऑटोसेव सक्षम करना**: वर्तमान सेटिंग्स को तुरंत localStorage में सेव करता है
- **ऑटोसेव अक्षम करना**: localStorage से सभी सेव की गई सेटिंग्स क्लियर करता है
- आपकी ऑटोसेव प्राथमिकता सत्रों में याद रखी जाती है

### कॉन्फ़िगरेशन आयात/निर्यात

आप JSON फ़ाइलों के माध्यम से अपनी कॉन्फ़िगरेशन साझा या बैकअप कर सकते हैं:

- **निर्यात**: वर्तमान कॉन्फ़िगरेशन को `claude-initializr-config.json` के रूप में डाउनलोड करने के लिए हेडर में अपलोड आइकन पर क्लिक करें
- **आयात**: पहले से निर्यात की गई JSON फ़ाइल चुनने के लिए डाउनलोड आइकन पर क्लिक करें

**यह कैसे काम करता है:**

- **निर्यात** सभी सेटिंग्स (बेस इमेज, सॉफ़्टवेयर चयन, पैकेज, कमांड, अनुमतियाँ, CLAUDE.md सामग्री) को एक JSON फ़ाइल में सहेजता है
- **आयात** फ़ाइल को मान्य करता है, परिवर्तनों का पूर्वावलोकन दिखाता है और लागू करने से पहले पुष्टि मांगता है
- सुरक्षा कारणों से, निर्यात की गई फ़ाइलों में **पर्यावरण चर के मान कभी शामिल नहीं होते** — केवल चर नाम निर्यात किए जाते हैं
- आयातित कॉन्फ़िगरेशन को टकराव से बचने के लिए नई आंतरिक ID मिलती हैं
- निर्यात प्रारूप में भविष्य की संगतता के लिए एक संस्करण फ़ील्ड (`"version": "1.0"`) शामिल है

### गोपनीयता और डेटा स्टोरेज

यह एप्लिकेशन आपकी गोपनीयता का सम्मान करता है:

- **केवल लोकल स्टोरेज**: सभी सेटिंग्स आपके ब्राउज़र में स्थानीय रूप से स्टोर होती हैं (localStorage)
- **कोई सर्वर संचार नहीं**: कभी भी कोई डेटा किसी सर्वर को नहीं भेजा जाता
- **डिज़ाइन से सुरक्षित**: एनवायरनमेंट वेरिएबल **वैल्यूज़ कभी स्टोर नहीं होती** - केवल वेरिएबल नाम सेव होते हैं
- **पूर्ण नियंत्रण**: आप हेडर में टॉगल का उपयोग करके किसी भी समय ऑटोसेव को अक्षम कर सकते हैं, जो सभी स्टोर किए गए डेटा को भी क्लियर करता है
- **सत्र-आधारित थीम**: पेज रीलोड पर थीम प्राथमिकता सिस्टम डिफ़ॉल्ट पर रीसेट हो जाती है

## सुरक्षा विशेषताएं

जेनरेट किए गए Docker कॉन्फ़िगरेशन में व्यापक सुरक्षा उपाय शामिल हैं:

### नेटवर्क फ़ायरवॉल

`init-firewall.sh` स्क्रिप्ट सख्त नेटवर्क आइसोलेशन लागू करती है:

- **iptables-आधारित फ़ायरवॉल** सभी आउटबाउंड ट्रैफ़िक के लिए DROP पॉलिसी के साथ
- **केवल अनुमति-सूची दृष्टिकोण** - केवल स्वीकृत डोमेन पहुंच योग्य हैं:
  - `api.anthropic.com` - Claude API
  - `npm registry` - पैकेज इंस्टॉलेशन
  - `github.com` - Git ऑपरेशन
  - `sentry.io` - त्रुटि रिपोर्टिंग
- **स्वचालित GitHub IP रिज़ॉल्यूशन** वेब, API और git एंडपॉइंट्स के लिए
- **होस्ट नेटवर्क आइसोलेशन** - लोकल नेटवर्क तक पहुंच रोकता है
- **फ़ायरवॉल सत्यापन** - टेस्ट सुनिश्चित करते हैं कि नियम सही ढंग से लागू हों

### Docker सुरक्षा हार्डनिंग

- **कैपेबिलिटी ड्रॉपिंग**: सभी Linux कैपेबिलिटीज़ हटा दी जाती हैं (`cap_drop: ALL`)
- **कोई प्रिविलेज एस्केलेशन नहीं**: `no-new-privileges:true`
- **रिसोर्स लिमिट्स**: CPU और मेमोरी कंस्ट्रेंट्स
- **रीड-ओनली माउंट्स**: संरक्षित फ़ाइलें रीड-ओनली के रूप में माउंट होती हैं
- **नॉन-रूट एक्ज़ीक्यूशन**: `node` उपयोगकर्ता के रूप में चलता है

## उपयोग

1. **बेस इमेज कॉन्फ़िगर करें**: Docker बेस इमेज का नाम और संस्करण सेट करें (जैसे, `node:24` या `node:22-slim`)

2. **सॉफ्टवेयर चुनें**: अपने कंटेनर में इंस्टॉल करने के लिए अतिरिक्त सॉफ्टवेयर चुनें

3. **कस्टम पैकेज और कमांड जोड़ें**:
   - कस्टम APT पैकेज जोड़ें (जैसे, `curl`, `graphviz`, `sqlite3`)
   - ग्लोबली इंस्टॉल करने के लिए कस्टम NPM पैकेज जोड़ें (जैसे, `eslint`, `prettier`)
   - चुनें कि NPM पैकेज `node` (डिफ़ॉल्ट) या `root` उपयोगकर्ता के रूप में इंस्टॉल होने चाहिए
   - बिल्ड के दौरान चलाने के लिए कस्टम RUN कमांड जोड़ें (जैसे, `pip install numpy`)
   - चुनें कि RUN कमांड `node` (डिफ़ॉल्ट) या `root` उपयोगकर्ता के रूप में चलनी चाहिए

4. **एनवायरनमेंट वेरिएबल्स सेट करें**: अपने प्रोजेक्ट के लिए आवश्यक एनवायरनमेंट वेरिएबल्स जोड़ें (जैसे, `ANTHROPIC_API_KEY`)

5. **संवेदनशील फ़ाइलें सुरक्षित करें**: सुरक्षित की जाने वाली फ़ाइलों के पाथ जोड़ें (जैसे, `.env.local`)

6. **CLAUDE.md संपादित करें**: Markdown एडिटर में Claude के लिए निर्देश लिखें

7. **अनुमतियाँ कॉन्फ़िगर करें**: settings.json कार्ड के माध्यम से अनुमति नियम सेट करें
   - ऑटो-अप्रूव्ड ऑपरेशनों के लिए `Allow` नियम जोड़ें
   - पुष्टि की आवश्यकता वाले ऑपरेशनों के लिए `Ask` नियम जोड़ें
   - प्रतिबंधित ऑपरेशनों के लिए `Deny` नियम जोड़ें
   - संरक्षित फ़ाइलें स्वचालित रूप से `Read()` अस्वीकृति नियमों के रूप में जोड़ी जाती हैं

8. **प्रीव्यू**: प्रीव्यू टैब में जेनरेट की गई कॉन्फ़िगरेशन फ़ाइलों की जांच करें

9. **डाउनलोड**: सभी फ़ाइलें प्राप्त करने के लिए "ZIP डाउनलोड करें" पर क्लिक करें

## जेनरेट की गई फ़ाइलों का उपयोग

1. ZIP फ़ाइल को अपनी प्रोजेक्ट डायरेक्टरी में एक्सट्रैक्ट करें

2. अपनी प्रोजेक्ट फ़ाइलों को `workspace` फ़ोल्डर में कॉपी करें (या अपना मौजूदा प्रोजेक्ट माउंट करें)

3. `.env` फ़ाइल में अपनी API कुंजी सेट करें:

   ```bash
   ANTHROPIC_API_KEY=आपकी-api-कुंजी-यहां
   ```

4. कंटेनर बिल्ड और रन करें:

   ```bash
   docker compose up --build
   ```

   **वैकल्पिक: कस्टम सॉफ़्टवेयर संस्करण**

   सॉफ़्टवेयर संस्करणों को बिल्ड आर्गुमेंट के माध्यम से कॉन्फ़िगर किया जा सकता है। डायनामिक संस्करण प्राप्त करने के लिए `latest` का उपयोग करें या एक स्पष्ट संस्करण निर्दिष्ट करें:

   ```bash
   docker compose build \
     --build-arg GO_VERSION=1.22.0 \
     --build-arg FLUTTER_VERSION=3.24.0 \
     --build-arg PYTHON_VERSION=3.12 \
     --build-arg TYPESCRIPT_VERSION=5.6.0
   ```

   | बिल्ड आर्गुमेंट | डिफ़ॉल्ट | विवरण |
   |-----------------|----------|--------|
   | `CLAUDE_CODE_VERSION` | `stable` | Claude Code संस्करण (`latest` या विशिष्ट जैसे `1.0.58`) |
   | `FLUTTER_VERSION` | `latest` | Flutter संस्करण (`latest` या विशिष्ट जैसे `3.24.0`) |
   | `GIT_DELTA_VERSION` | `0.18.2` | diff हाइलाइटिंग के लिए Git delta संस्करण |
   | `GO_VERSION` | `latest` | Go संस्करण (`latest` या विशिष्ट जैसे `1.22.0`) |
   | `PYTHON_VERSION` | `3` | Python संस्करण (उदा. `3`, `3.12`) |
   | `TYPESCRIPT_VERSION` | `latest` | TypeScript संस्करण (`latest` या विशिष्ट जैसे `5.6.0`) |
   | `ZSH_IN_DOCKER_VERSION` | `1.2.0` | शेल सेटअप के लिए zsh-in-docker संस्करण |

   **वैकल्पिक: कस्टम डाउनलोड URLs**

   यदि आपको पैकेज डाउनलोड के लिए मिरर या प्रॉक्सी का उपयोग करना है, तो आप बिल्ड के दौरान डिफ़ॉल्ट URLs को ओवरराइड कर सकते हैं। सभी URLs क्वेरी पैरामीटर का समर्थन करते हैं:

   ```bash
   docker compose build \
     --build-arg GO_JSON_URL=https://my-mirror.example.com/golang/?mode=json \
     --build-arg GO_DOWNLOAD_URL=https://my-mirror.example.com/golang \
     --build-arg RUSTUP_INSTALL_URL=https://my-mirror.example.com/rustup/rustup-init.sh \
     --build-arg FLUTTER_JSON_URL=https://my-mirror.example.com/flutter/releases_linux.json \
     --build-arg FLUTTER_BASE_URL=https://my-mirror.example.com/flutter/releases \
     --build-arg UV_INSTALL_SCRIPT_URL=https://my-mirror.example.com/uv/install.sh
   ```

   | बिल्ड आर्गुमेंट | डिफ़ॉल्ट | विवरण |
   |-----------------|----------|--------|
   | `GO_JSON_URL` | `https://go.dev/dl/?mode=json` | Go वर्जन JSON API URL (केवल "latest" के लिए) |
   | `GO_DOWNLOAD_URL` | `https://go.dev/dl` | Go आर्काइव डाउनलोड के लिए बेस URL |
   | `RUSTUP_INSTALL_URL` | `https://sh.rustup.rs` | rustup इंस्टॉल स्क्रिप्ट URL |
   | `FLUTTER_JSON_URL` | `https://storage.googleapis.com/flutter_infra_release/releases/releases_linux.json` | Flutter रिलीज़ JSON API URL (केवल "latest" के लिए) |
   | `FLUTTER_BASE_URL` | `https://storage.googleapis.com/flutter_infra_release/releases` | Flutter आर्काइव डाउनलोड के लिए बेस URL |
   | `UV_INSTALL_SCRIPT_URL` | `https://astral.sh/uv/install.sh` | uv इंस्टॉल स्क्रिप्ट URL |

5. कंटेनर से कनेक्ट करें:

   ```bash
   docker compose exec claude zsh
   ```

6. फ़ायरवॉल इनिशियलाइज़ करें (sudo पासवर्ड आवश्यक):

   ```bash
   sudo /usr/local/bin/init-firewall.sh
   ```

7. Claude Code शुरू करें:
   ```bash
   claude
   ```

## समस्या निवारण

यदि आपको फ़ायरवॉल सक्षम करने के बाद नेटवर्क समस्याएं आती हैं:

```bash
sudo iptables -L -n

# ब्लॉक किए गए कनेक्शन देखें
sudo iptables -L -n -v | grep DROP

# फ़ायरवॉल रीसेट करें (सभी ट्रैफ़िक की अनुमति दें)
sudo iptables -F
```

```bash
docker compose logs
```

सभी सेव की गई सेटिंग्स क्लियर करने और नए सिरे से शुरू करने के लिए, अपने ब्राउज़र का डेवलपर कंसोल खोलें और चलाएं:

```javascript
localStorage.removeItem("claude-initializr-config");

localStorage.removeItem("claude-initializr-autosave");
```

फिर पेज रीलोड करें।

वैकल्पिक रूप से, आप सेटिंग्स को सेव होने से रोकने के लिए हेडर में टॉगल का उपयोग करके ऑटोसेव को अक्षम कर सकते हैं।

  - सक्षम होने पर स्वचालित रूप से `ANTHROPIC_BASE_URL` और `ANTHROPIC_AUTH_TOKEN` सेट करता है
  - Ollama अक्षम होने पर एनवायरनमेंट वेरिएबल्स हटा दिए जाते हैं
- होस्ट नेटवर्क एक्सेस के लिए docker-compose.yaml में `extra_hosts` कॉन्फ़िगरेशन जोड़ा गया

### v4.0.2

- **प्रमुख UI/UX पुनर्डिजाइन**: सुधारी हुई उपयोगिता के लिए संपूर्ण इंटरफ़ेस ओवरहॉल
  - ऊर्ध्वाधर कार्ड-आधारित लेआउट को साइडबार + स्प्लिट पेन लेआउट से बदला गया
  - कीबोर्ड शॉर्टकट के साथ त्वरित सेक्शन स्विचिंग के लिए साइडबार नेविगेशन (`Ctrl/⌘ + 1-5`)
  - संपादक और लाइव प्रीव्यू को साइड-बाय-साइड के साथ आकार बदलने योग्य स्प्लिट पेन
  - संक्षिप्त साइडबार जो आइकन-केवल मोड के साथ संक्षिप्त होता है (`Ctrl/⌘ + B` को टॉगल करने के लिए)
  - संज्ञानात्मक भार को कम करने के लिए अकॉर्डियन सेक्शन के साथ प्रगतिशील प्रकटीकरण
- **RTL भाषा समर्थन**: अरबी, हिब्रू और उर्दू के लिए पूर्ण दाएं-से-बाएं समर्थन
  - RTL भाषाओं के लिए साइडबार स्वचालित रूप से दाहिनी ओर स्थित होता है
  - सभी UI तत्व ठीक से प्रतिबिंबित होते हैं
- **प्रतिक्रियाशील सुधार**:
  - साइडबार टैबलेट स्क्रीन पर संक्षिप्त शुरू होता है (768–1023px)
  - मोबाइल-अनुकूलित लेआउट बॉटम शीट प्रीव्यू के साथ
  - टच-अनुकूल अकॉर्डियन ट्रिगर (44px न्यूनतम ऊंचाई)
- **स्वागत डायलॉग**: पहली बार आने वाले आगंतुक एक स्वागत डायलॉग देखते हैं स्थिर कार्ड के बजाय
  - साइडबार में "के बारे में" के माध्यम से फिर से खोला जा सकता है
- **हटाए गए लीगेसी घटक**: पुराने कार्ड-आधारित घटकों को साफ किया गया
- नए लेआउट के साथ काम करने के लिए कीबोर्ड शॉर्टकट अपडेट किए गए

### v3.2.1

- अनडू/रीडू कार्यक्षमता के साथ कॉन्फ़िगरेशन इतिहास जोड़ा गया
  - विलंबित स्नैपशॉट के साथ स्वचालित परिवर्तन ट्रैकिंग (500ms)
  - कीबोर्ड शॉर्टकट के साथ अनडू/रीडू (`Ctrl/⌘ + Z` / `Ctrl/⌘ + Y`)
  - टाइमस्टैम्प और परिवर्तन विवरण के साथ इतिहास पैनल
  - कॉन्फ़िगरेशन की तुलना के लिए डिफ व्यू
  - किसी भी पिछली स्थिति में पुनर्स्थापित करें
  - स्थायित्व के लिए IndexedDB स्टोरेज (अधिकतम 50 प्रविष्टियाँ)
- VS Code और GitHub Codespaces के लिए DevContainer समर्थन जोड़ा गया
  - `devcontainer.json` कॉन्फ़िगरेशन जनरेट करें
  - VS Code एक्सटेंशन और सेटिंग्स कॉन्फ़िगर करें
  - Dev Container सुविधाएं जोड़ें
  - पोर्ट फॉरवर्डिंग सेट करें
  - लाइफसाइकल कमांड कॉन्फ़िगर करें (post-create, post-start, post-attach)
  - चयनित सॉफ़्टवेयर के आधार पर स्वचालित एक्सटेंशन अनुशंसाएं
- DevContainer कार्ड पर स्क्रॉल करने के लिए कीबोर्ड शॉर्टकट `Ctrl/⌘ + 5` जोड़ा गया
- DevContainer सुविधा के साथ स्वागत अनुभाग अपडेट किया गया
