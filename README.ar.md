## الميزات

### تكوين Dockerfile

- **الصورة الأساسية**: قم بتكوين اسم وإصدار صورة Docker الأساسية (الافتراضي: `node:24`)
- **اختيار البرامج**: اختر برامج إضافية للتثبيت:
  - ffmpeg (معالجة الصوت/الفيديو)
  - Flutter (يتضمن Dart و Android SDK)
  - Go
  - ImageMagick (معالجة الصور)
  - Python 3
  - Rust (يتضمن مدير الحزم Cargo)
  - TypeScript
  - uv (مثبّت حزم Python سريع، يوصي بـ Python)
  - Ollama (الاتصال بنسخة Ollama محلية لاستخدام نماذج مفتوحة المصدر)
- **تكوين الإصدارات**: يتم تكوين إصدارات البرامج عبر وسائط بناء Docker (مثال: `--build-arg GO_VERSION=1.22.0`)
- **حزم APT مخصصة**: أضف حزم Debian/Ubuntu إضافية للتثبيت في الحاوية
- **حزم NPM مخصصة**: أضف حزم NPM إضافية للتثبيت عالمياً، مع خيار التثبيت كمستخدم `root` أو `node`
- **أوامر RUN مخصصة**: أضف أوامر shell مخصصة للتنفيذ أثناء بناء صورة Docker، مع خيار التشغيل كمستخدم `root` أو `node`

### تكوين docker-compose.yaml

- **متغيرات البيئة**: قم بتكوين متغيرات البيئة لملف `.env` الخاص بك
- **الملفات المحمية**: حدد الملفات التي يجب حمايتها عن طريق تركيب ملفات فارغة للقراءة فقط (يمنع الوصول إلى الملفات الحساسة مثل `.env.local`)

### محرر CLAUDE.md

- محرر Markdown مع تمييز بناء الجملة
- وظيفة المعاينة المدمجة
- اكتب تعليمات خاصة بالمشروع لـ Claude

### تكوين settings.json

- **قواعد الأذونات**: قم بتكوين أذونات Claude Code لإدارة الوصول إلى الملفات
  - `Allow` - قواعد للعمليات المسموح بها تلقائياً
  - `Ask` - قواعد تتطلب تأكيد المستخدم
  - `Deny` - قواعد يتم رفضها دائماً
- **التوجيهات المدعومة**:
  - `Read()` - يحدد الملفات التي يمكن لـ Claude قراءتها (مثال: `Read(src/**)`)
  - `Edit()` - يحدد الملفات التي يمكن لـ Claude تعديلها (مثال: `Edit(.env)`)
  - `WebFetch()` - يتحكم في الوصول إلى الشبكة (مثال: `WebFetch(https://api.github.com:*)`)
- **التكامل التلقائي**: تُضاف الملفات المحمية تلقائياً كقواعد رفض `Read()`
- **دعم أنماط Glob**: استخدم أنماط مثل `src/**` للمطابقة التكرارية

### تكوين DevContainer (VS Code / GitHub Codespaces)

- **تكامل VS Code**: إنشاء `devcontainer.json` لـ VS Code Dev Containers
- **GitHub Codespaces**: تكوين متوافق للتطوير على GitHub Codespaces
- **الإضافات**: تكوين إضافات VS Code للتثبيت التلقائي
- **الإعدادات**: تحديد إعدادات VS Code لبيئة الحاوية
- **الميزات**: إضافة Dev Container Features (مثل: GitHub CLI، لغات إضافية)
- **إعادة توجيه المنافذ**: تكوين المنافذ لإعادة توجيهها من الحاوية
- **أوامر دورة الحياة**: إعداد أوامر لأحداث post-create و post-start و post-attach
- **الإضافات الموصى بها**: توصيات تلقائية للإضافات بناءً على البرامج المحددة

### اختصارات لوحة المفاتيح

تستخدم جميع الاختصارات `Ctrl` على Windows/Linux و `⌘` (Cmd) على macOS.

| الاختصار | الإجراء |
| -------- | ------- |
| `Ctrl/⌘ + S` | تنزيل ZIP |
| `Ctrl/⌘ + E` | تبديل جزء المعاينة |
| `Ctrl/⌘ + B` | تبديل الشريط الجانبي |
| `Ctrl/⌘ + Z` | تراجع |
| `Ctrl/⌘ + Y` | إعادة |
| `Ctrl/⌘ + Shift + Z` | إعادة (بديل) |
| `Ctrl/⌘ + Shift + D` | تبديل الوضع الداكن/الفاتح |
| `Ctrl/⌘ + Shift + X` | إعادة التعيين إلى الافتراضي |

### آلية الحفظ التلقائي

يمكن تبديل ميزة الحفظ التلقائي باستخدام أيقونة الحفظ في الرأس:

| الأيقونة        | الحالة    | السلوك                                                        |
| --------------- | --------- | ------------------------------------------------------------- |
| 💾 (حفظ)        | مُفعّل    | يتم حفظ جميع التغييرات تلقائياً في localStorage               |
| 🚫💾 (إيقاف)    | مُعطّل    | لا يتم حفظ التغييرات؛ يتم مسح البيانات الموجودة               |

**كيف يعمل:**

- **تفعيل الحفظ التلقائي**: يحفظ الإعدادات الحالية فوراً في localStorage
- **تعطيل الحفظ التلقائي**: يمسح جميع الإعدادات المحفوظة من localStorage
- يتم تذكر تفضيل الحفظ التلقائي عبر الجلسات

### استيراد/تصدير الإعدادات

يمكنك مشاركة أو نسخ إعداداتك احتياطيًا عبر ملفات JSON:

- **التصدير**: انقر على أيقونة الرفع في الرأس لتنزيل إعداداتك الحالية كـ `claude-initializr-config.json`
- **الاستيراد**: انقر على أيقونة التنزيل لاختيار ملف JSON تم تصديره مسبقًا

**كيف يعمل:**

- **التصدير** يحفظ جميع الإعدادات (الصورة الأساسية، اختيار البرامج، الحزم، الأوامر، الأذونات، محتوى CLAUDE.md) في ملف JSON واحد
- **الاستيراد** يتحقق من صحة الملف، ويعرض معاينة للتغييرات، ويطلب التأكيد قبل التطبيق
- لأسباب أمنية، **لا يتم تضمين قيم متغيرات البيئة أبدًا** في الملفات المصدرة — يتم تصدير أسماء المتغيرات فقط
- تحصل الإعدادات المستوردة على معرفات داخلية جديدة لمنع التعارضات
- يتضمن تنسيق التصدير حقل إصدار (`"version": "1.0"`) للتوافق المستقبلي

### الخصوصية وتخزين البيانات

يحترم هذا التطبيق خصوصيتك:

- **التخزين المحلي فقط**: يتم تخزين جميع الإعدادات محلياً في متصفحك (localStorage)
- **لا يوجد اتصال بالخادم**: لا يتم إرسال أي بيانات إلى أي خادم أبداً
- **آمن بالتصميم**: **قيم** متغيرات البيئة **لا تُخزّن أبداً** - يتم حفظ أسماء المتغيرات فقط
- **تحكم كامل**: يمكنك تعطيل الحفظ التلقائي في أي وقت باستخدام المفتاح في الرأس، مما يمسح أيضاً جميع البيانات المخزنة
- **سمة قائمة على الجلسة**: تتم إعادة تعيين تفضيل السمة إلى الافتراضي للنظام عند إعادة تحميل الصفحة

## ميزات الأمان

يتضمن تكوين Docker المُنشأ إجراءات أمنية شاملة:

### جدار حماية الشبكة

ينفذ سكريبت `init-firewall.sh` عزلاً صارماً للشبكة:

- **جدار حماية قائم على iptables** مع سياسة DROP لجميع حركة المرور الصادرة
- **نهج القائمة المسموح بها فقط** - يمكن الوصول إلى النطاقات المسموح بها فقط:
  - `api.anthropic.com` - واجهة Claude API
  - `npm registry` - تثبيت الحزم
  - `github.com` - عمليات Git
  - `sentry.io` - الإبلاغ عن الأخطاء
- **حل تلقائي لعناوين IP الخاصة بـ GitHub** لنقاط نهاية الويب وAPI وgit
- **عزل شبكة المضيف** - يمنع الوصول إلى الشبكة المحلية
- **التحقق من جدار الحماية** - تضمن الاختبارات تطبيق القواعد بشكل صحيح

### تقوية أمان Docker

- **إسقاط القدرات**: تتم إزالة جميع قدرات Linux (`cap_drop: ALL`)
- **لا تصعيد للامتيازات**: `no-new-privileges:true`
- **حدود الموارد**: قيود على المعالج والذاكرة
- **تركيبات للقراءة فقط**: يتم تركيب الملفات المحمية للقراءة فقط
- **تنفيذ بدون root**: يعمل كمستخدم `node`

## الاستخدام

1. **تكوين الصورة الأساسية**: عيّن اسم وإصدار صورة Docker الأساسية (مثل `node:24` أو `node:22-slim`)

2. **اختيار البرامج**: اختر البرامج الإضافية للتثبيت في حاويتك

3. **إضافة حزم وأوامر مخصصة**:
   - أضف حزم APT مخصصة (مثل `curl`، `graphviz`، `sqlite3`)
   - أضف حزم NPM مخصصة للتثبيت عالمياً (مثل `eslint`، `prettier`)
   - اختر ما إذا كان يجب تثبيت حزم NPM كمستخدم `node` (افتراضي) أو `root`
   - أضف أوامر RUN مخصصة للتنفيذ أثناء البناء (مثل `pip install numpy`)
   - اختر ما إذا كان يجب تشغيل أوامر RUN كمستخدم `node` (افتراضي) أو `root`

4. **تعيين متغيرات البيئة**: أضف أي متغيرات بيئة يحتاجها مشروعك (مثل `ANTHROPIC_API_KEY`)

5. **حماية الملفات الحساسة**: أضف مسارات الملفات التي يجب حمايتها (مثل `.env.local`)

6. **تحرير CLAUDE.md**: اكتب تعليمات لـ Claude في محرر Markdown

7. **تكوين الأذونات**: قم بإعداد قواعد الأذونات عبر بطاقة settings.json
   - أضف قواعد `Allow` للعمليات المعتمدة تلقائياً
   - أضف قواعد `Ask` للعمليات التي تتطلب تأكيداً
   - أضف قواعد `Deny` للعمليات المحظورة
   - تُضاف الملفات المحمية تلقائياً كقواعد رفض `Read()`

8. **معاينة**: تحقق من ملفات التكوين المُنشأة في علامات التبويب

9. **تنزيل**: انقر على "تنزيل ZIP" للحصول على جميع الملفات

## استخدام الملفات المُنشأة

1. استخرج ملف ZIP إلى دليل مشروعك

2. انسخ ملفات مشروعك إلى مجلد `workspace` (أو قم بتركيب مشروعك الحالي)

3. عيّن مفتاح API الخاص بك في ملف `.env`:

   ```bash
   ANTHROPIC_API_KEY=مفتاح-api-الخاص-بك-هنا
   ```

4. بناء وتشغيل الحاوية:

   ```bash
   docker compose up --build
   ```

   **اختياري: إصدارات البرامج المخصصة**

   يمكن تكوين إصدارات البرامج عبر وسائط البناء. استخدم `latest` لجلب الإصدار ديناميكياً أو حدد إصداراً صريحاً:

   ```bash
   docker compose build \
     --build-arg GO_VERSION=1.22.0 \
     --build-arg FLUTTER_VERSION=3.24.0 \
     --build-arg PYTHON_VERSION=3.12 \
     --build-arg TYPESCRIPT_VERSION=5.6.0
   ```

   | وسيط البناء | الافتراضي | الوصف |
   |-------------|-----------|-------|
   | `CLAUDE_CODE_VERSION` | `stable` | إصدار Claude Code (`latest` أو محدد مثل `1.0.58`) |
   | `FLUTTER_VERSION` | `latest` | إصدار Flutter (`latest` أو محدد مثل `3.24.0`) |
   | `GIT_DELTA_VERSION` | `0.18.2` | إصدار Git delta لتمييز الفروقات |
   | `GO_VERSION` | `latest` | إصدار Go (`latest` أو محدد مثل `1.22.0`) |
   | `PYTHON_VERSION` | `3` | إصدار Python (مثال: `3`، `3.12`) |
   | `TYPESCRIPT_VERSION` | `latest` | إصدار TypeScript (`latest` أو محدد مثل `5.6.0`) |
   | `ZSH_IN_DOCKER_VERSION` | `1.2.0` | إصدار zsh-in-docker لإعداد الصدفة |

   **اختياري: عناوين URL مخصصة للتنزيل**

   إذا كنت بحاجة إلى استخدام مرآة أو وكيل لتنزيل الحزم، يمكنك تجاوز عناوين URL الافتراضية أثناء البناء. جميع عناوين URL تدعم معلمات الاستعلام:

   ```bash
   docker compose build \
     --build-arg GO_JSON_URL=https://my-mirror.example.com/golang/?mode=json \
     --build-arg GO_DOWNLOAD_URL=https://my-mirror.example.com/golang \
     --build-arg RUSTUP_INSTALL_URL=https://my-mirror.example.com/rustup/rustup-init.sh \
     --build-arg FLUTTER_JSON_URL=https://my-mirror.example.com/flutter/releases_linux.json \
     --build-arg FLUTTER_BASE_URL=https://my-mirror.example.com/flutter/releases \
     --build-arg UV_INSTALL_SCRIPT_URL=https://my-mirror.example.com/uv/install.sh
   ```

   | وسيط البناء | الافتراضي | الوصف |
   |-------------|-----------|-------|
   | `GO_JSON_URL` | `https://go.dev/dl/?mode=json` | عنوان URL لواجهة JSON لإصدارات Go (فقط عند اختيار "latest") |
   | `GO_DOWNLOAD_URL` | `https://go.dev/dl` | عنوان URL الأساسي لتنزيل أرشيفات Go |
   | `RUSTUP_INSTALL_URL` | `https://sh.rustup.rs` | عنوان URL لسكربت تثبيت rustup |
   | `FLUTTER_JSON_URL` | `https://storage.googleapis.com/flutter_infra_release/releases/releases_linux.json` | عنوان URL لواجهة JSON لإصدارات Flutter (فقط عند اختيار "latest") |
   | `FLUTTER_BASE_URL` | `https://storage.googleapis.com/flutter_infra_release/releases` | عنوان URL الأساسي لتنزيل أرشيفات Flutter |
   | `UV_INSTALL_SCRIPT_URL` | `https://astral.sh/uv/install.sh` | عنوان URL لسكربت تثبيت uv |

5. الاتصال بالحاوية:

   ```bash
   docker compose exec claude zsh
   ```

6. تهيئة جدار الحماية (يتطلب كلمة مرور sudo):

   ```bash
   sudo /usr/local/bin/init-firewall.sh
   ```

7. بدء Claude Code:
   ```bash
   claude
   ```

## استكشاف الأخطاء وإصلاحها

### مشاكل جدار الحماية

إذا واجهت مشاكل في الشبكة بعد تفعيل جدار الحماية:

```bash
# التحقق من حالة جدار الحماية
sudo iptables -L -n

# عرض الاتصالات المحظورة
sudo iptables -L -n -v | grep DROP

# إعادة تعيين جدار الحماية (يسمح بجميع حركة المرور)
sudo iptables -F
```

### الحاوية لا تبدأ

```bash
# التحقق من السجلات
docker compose logs

# إعادة البناء بدون ذاكرة التخزين المؤقت
docker compose build --no-cache
```

### تم رفض الإذن

تأكد من أن دليل workspace لديه الأذونات الصحيحة:

```bash
chmod -R 755 workspace
```

### إعادة تعيين إعدادات التطبيق

لمسح جميع الإعدادات المحفوظة والبدء من جديد، افتح وحدة تحكم المطور في متصفحك ونفذ:

```javascript
localStorage.removeItem("claude-initializr-config");
localStorage.removeItem("claude-initializr-welcome-dismissed");
localStorage.removeItem("claude-initializr-autosave");
```

ثم أعد تحميل الصفحة.

بدلاً من ذلك، يمكنك تعطيل الحفظ التلقائي باستخدام المفتاح في الرأس لمنع حفظ الإعدادات.

## المساهمة

المساهمات مرحب بها! لا تتردد في تقديم طلب سحب.

1. قم بعمل fork للمستودع
2. أنشئ فرع الميزة الخاص بك (`git checkout -b feature/ميزة-رائعة`)
3. قم بالتزام تغييراتك (`git commit -m 'إضافة ميزة رائعة'`)
4. ادفع إلى الفرع (`git push origin feature/ميزة-رائعة`)
5. افتح طلب سحب

### إضافة لغة جديدة

1. أنشئ ملف locale جديد في `src/i18n/locales/` (مثل `fr.ts`)
2. استورد وقم بتنفيذ واجهة `Translations` من `types.ts`
3. انسخ الهيكل من `en.ts` وترجم جميع النصوص
4. أضف استيراد اللغة إلى `src/i18n/index.ts`
5. أضف خيار اللغة إلى `LanguageSwitcher.tsx`

   ```bash
   git push origin v1.0.0
   ```

2. سير العمل يقوم تلقائياً بـ:
   - بناء المشروع
   - إنشاء أرشيف ZIP من مجلد `dist/`
   - نشر GitHub Release مع ملاحظات الإصدار المُولّدة تلقائياً
